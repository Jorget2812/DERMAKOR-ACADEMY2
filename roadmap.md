# Project Roadmap

## MVP (Weeks 1-3)
- **Foundation**: Next.js app, Supabase, basic Auth.
- **Verification Flow**: Public form, Admin approve/create user.
- **Shop**: Public/Private product listing, prices with tier discounts.
- **Payments**: Stripe Checkout + Webhook for stock/orders.
- **Academy**: Basic Course/Lesson view and progress tracking.
- **Admin**: Verifications, Users, and Basic Shop management.

## V1 (Week 4-6)
- **Extended Academy**: PDF Resource library with signed URLs.
- **Multi-language**: Fully localized UI in fr/it/de.
- **Order Tracking**: Better status updates for orders.
- **Analytics**: Admin dashboard with sales and academy engagement metrics.

## V2 (Future)
- **Real-time Inventory**: External ERP integration.
- **Community/Forum**: For academy students.
- **Advanced Marketing**: Discount codes and subscription levels.
- **Mobile App**: PWA or Native wrapper for Academy.
