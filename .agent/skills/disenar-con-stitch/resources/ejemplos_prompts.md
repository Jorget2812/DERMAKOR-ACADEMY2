# Ejemplos de Prompts para Stitch

Usa estos ejemplos como base para generar interfaces de alta calidad.

## 1. Landing Page para App de Fintech (Premium Dark)
> "Crea una página de aterrizaje para una aplicación de finanzas moderna llamada 'LuminaPay'. 
> **Estética**: Diseño ultra-premium en modo oscuro con gradientes azul profundo y púrpura. 
> **Secciones**: 
> - Hero potente con una tarjeta de crédito 3D realista.
> - Sección de 'Beneficios' con iconos minimalistas.
> - Tabla de transacciones recientes con efecto de desenfoque de fondo (glassmorphism).
> - Botones de acción con micro-gradientes y bordes suaves."

## 2. Dashboard de Administración (SaaS)
> "Diseña un dashboard de analíticas para una plataforma de marketing. 
> **Estilo**: Fondo blanco limpio, fuentes sans-serif modernas (Inter o Roboto). 
> **Componentes**: 
> - Sidebar lateral delgada con iconos de línea.
> - 4 tarjetas de KPI en la parte superior con gráficos de tendencia pequeños.
> - Un gráfico de área grande en el centro mostrando crecimiento de usuarios.
> - Tabla de usuarios recientes con estados de colores suaves (verde para activo, gris para offline)."

## 3. Pantalla de Perfil de E-commerce (Mobile)
> "Genera una pantalla de perfil de usuario para una tienda de ropa de lujo.
> **Plataforma**: Mobile.
> **Elementos**: 
> - Cabecera con foto de perfil circular y nombre en tipografía elegante.
> - Grid de 'Mis Favoritos' con imágenes de alta resolución de productos.
> - Lista de opciones de configuración con iconos sutiles a la derecha.
> - Diseño minimalista con mucho aire y tipografía de alto contraste."
