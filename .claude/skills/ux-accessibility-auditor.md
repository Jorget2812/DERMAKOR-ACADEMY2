# UX & Accessibility Auditor Skill

**Goal:** Ensure application usability and WCAG compliance across all devices.

## Steps

1.  **Semantic Audit:**
    *   Verify correct use of HTML5 semantic elements (main, nav, section).
    *   Ensure heading hierarchy (h1-h6) is logical and consistent.
2.  **Interactive Elements:**
    *   Check keyboard focus states and navigation patterns.
    *   Verify ARIA labels and roles for complex components (modals, dropdowns).
3.  **Visual Quality:**
    *   Check for color contrast compliance (WCAG AA standard).
    *   Verify mobile-first responsiveness and touch target sizes.
4.  **Localization Review:**
    *   Ensure all strings are correctly translated (FR/IT/DE).
    *   Check for layout breaks with longer translated strings.

## Rules

*   **Mobile-First:** Always audit mobile view before tablet/desktop.
*   **Accessibility is Not Optional:** Follow WCAG 2.1 AA guidelines.
*   **Predictable UI:** Maintain consistency with established project patterns.
*   **No Placeholders:** Ensure real content and labels are used.

## Expected Output

*   Audit report with specific accessibility/UX improvements and implemented fixes.
